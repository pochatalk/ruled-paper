# つくルーズリーフ

ブラウザだけで、寸法が正確な**印刷用のルーズリーフ（罫線紙）PDF**を作れるツールである。サーバー不要・インストール不要で、`index.html` を開くだけで使える。

初期状態は **B5・A罫（7mm）** になっている。

## 使い方

1. `index.html` をブラウザで開く
2. 左の設定パネルで用紙・罫線などを調整する（右側に実寸プレビューがリアルタイム表示される）
3. 下の **「PDFをダウンロード」** または **「ブラウザで印刷」** で出力する

### 印刷のコツ

寸法を正確に出すため、印刷時は **「実際のサイズ（100%・余白なし）」** を選ぶとよい。拡大・縮小やフチ合わせが入ると罫線の間隔がずれる。

## できること

- **用紙サイズ**：B5 / A4 / A5 / レター / カスタム（mm指定）、縦横の向き
- **罫線タイプ**：横罫 / 方眼 / ドット / 無地
  - 横罫：行間（A罫7mm・B罫6mm・C罫5mmのプリセットあり）、上下端を実線・中間を破線に、線の太さ調整
  - 方眼：マス目サイズ、破線切替、線の太さ
  - ドット：点間隔、ドット径
- **線の色**：カラーピッカーで自由に指定
- **ヘッダー**：左 / 中央 / 右の3か所に文字を配置（空欄にするとその欄は非表示）
- **マージン**：上下左右を個別に指定
- **枚数**：1〜100枚の同一ページをまとめて出力
- **初期設定に戻す**ボタンで、いつでもB5・A罫の既定へリセット

## 出力方法

- **PDFダウンロード**：[pdf-lib](https://pdf-lib.js.org/) で寸法どおりのPDFを生成する（主な出力経路）
- **ブラウザ印刷**：`@page` を使い、用紙サイズに合わせて印刷する

## 技術メモ

- バニラ JavaScript（ビルド不要）
- プレビュー（SVG）とPDFで座標計算ロジックを共有し、表示と出力のズレを防いでいる
- pdf-lib は CDN から読み込む（PDF生成時のみ必要。プレビューと印刷はオフラインでも動作する）
